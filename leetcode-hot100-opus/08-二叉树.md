# 08 · 二叉树（15 题）

## 套路总纲

二叉树是**递归思维的训练场**。15 题里没有一道需要复杂数据结构，难点全在「能不能把问题正确地交给子树」。

**递归三问**（写每道题之前先答一遍）

1. **这个函数返回什么？** 深度？子树最大和？是否合法？——返回值定义错了，后面全错。
2. **base case 是什么？** 99% 是 `if (!node) return ...`，注意返回的"零值"要和语义匹配（深度返回 0，最大和返回 0 或 `INT_MIN`）。
3. **在哪个位置干活？** 这是二叉树题的核心分水岭：

   ```cpp
   void dfs(TreeNode* node) {
       if (!node) return;
       // ← 前序位置：自上而下，此时还不知道子树的任何信息
       dfs(node->left);
       // ← 中序位置：左子树已完成（BST 在此处是升序！）
       dfs(node->right);
       // ← 后序位置：左右子树信息都拿到了，可以汇总
   }
   ```

**两种解题思路**（一定要能分清）

| | 遍历式 | 分解子问题式 |
|---|---|---|
| 函数签名 | `void dfs(...)` | `int/bool f(...)` 有返回值 |
| 答案存哪 | 成员变量 / 引用参数 | 返回值层层向上汇总 |
| 典型题 | 199、437、124、543 | 104、98、226、236 |

遇到「求整棵树的某个全局最值」（124、543、437），几乎一定是**遍历式 + 后序位置统计 + 成员变量记录答案**，而且函数返回值和答案往往**不是同一个东西**（124 返回单边贡献，答案是拐点路径），这是这类题最容易翻车的地方。

**四个必背模板**

1. **BFS 层序**：`int sz = q.size()` 先固定本层节点数——102、199 的骨架。
2. **中序迭代**：显式栈 + `while (cur) { st.push(cur); cur = cur->left; }`——94、230。
3. **BST 性质**：**中序遍历 = 升序序列**。看到 BST 就先想中序（98 验证、230 第 K 小、530 最小差值）。
4. **上下界递归**：把父节点的约束往下传（98）——「自上而下传信息」的代表。

**难度递进**：94/104/226/101 是手感 → 543/102/108/199 是模板应用 → 98/230/114/105 要想清性质 → 437/236/124 是硬题。**124 和 236 是面试高频**。

**节点定义**（本文件所有代码共用）

```cpp
struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode* l, TreeNode* r) : val(x), left(l), right(r) {}
};
```

### 94. 二叉树的中序遍历（简单）

**题意**  返回中序遍历（左 → 根 → 右）的值序列。

**暴力**  递归三行就完事，本题真正想考的是**迭代写法**——面试官说「不用递归再写一遍」的概率极高。

**关键洞察**

递归之所以能工作，是因为**调用栈帮你记住了「回来之后该干什么」**。手写迭代就是手动模拟这个栈：

- 一路向左走到底，把路过的节点全压栈（这些节点的左子树还没处理完，**不能急着输出**）。
- 弹出栈顶，此时它的左子树已经彻底处理完 → **这时才能输出它**（中序）。
- 然后转向它的右子树，重复上述过程。

`cur` 的作用是「下一个待展开的子树根」，`nullptr` 表示「这一侧空了，该回退了」。所以循环条件是 `while (cur || !st.empty())`——**两者都空才算真结束**，只写 `!st.empty()` 会在开头就退出。

**最优解（C++）**

```cpp
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> ans;
        stack<TreeNode*> st;
        TreeNode* cur = root;
        while (cur || !st.empty()) {
            while (cur) {                 // 一路向左，沿途入栈
                st.push(cur);
                cur = cur->left;
            }
            cur = st.top(); st.pop();     // 左子树处理完，弹出即可输出
            ans.push_back(cur->val);
            cur = cur->right;             // 转向右子树
        }
        return ans;
    }
};
```

递归版（面试先写这个，再问要不要迭代）：

```cpp
void dfs(TreeNode* node, vector<int>& ans) {
    if (!node) return;
    dfs(node->left, ans);
    ans.push_back(node->val);   // 中序位置
    dfs(node->right, ans);
}
```

**进阶：Morris 遍历，O(1) 空间**

利用左子树的**最右节点（中序前驱）**的空 `right` 指针当"线索"，指回当前节点，这样从左子树走完能自动回到根，不需要栈：

```cpp
vector<int> inorderTraversal(TreeNode* root) {
    vector<int> ans;
    TreeNode* cur = root;
    while (cur) {
        if (!cur->left) {                        // 没有左子树，直接输出并右转
            ans.push_back(cur->val);
            cur = cur->right;
        } else {
            TreeNode* pre = cur->left;
            while (pre->right && pre->right != cur) pre = pre->right;  // 找中序前驱
            if (!pre->right) {
                pre->right = cur;                // 建线索，第一次到达 cur
                cur = cur->left;
            } else {
                pre->right = nullptr;            // 拆线索，说明左子树已遍历完
                ans.push_back(cur->val);         // 第二次到达 cur，此时输出
                cur = cur->right;
            }
        }
    }
    return ans;
}
```

**复杂度**  时间 O(n)；空间：递归/迭代 O(h)（h 为树高，最坏退化成链时 O(n)），Morris O(1)。

**边界与坑**
- 迭代版循环条件**必须**是 `cur || !st.empty()`。
- `ans.push_back` 的位置决定遍历序：放在「向左压栈」之前是前序，放在弹栈之后是中序。**前序的迭代改法**：压栈时就输出，且**先压右子树再压左子树**（栈是后进先出）。
- 后序迭代最麻烦，实战技巧：按「根→右→左」做前序，最后把结果 `reverse`，即得「左→右→根」。
- Morris 会**临时修改树的结构**，遍历结束后恢复原状。多线程环境或不允许改树时不能用，面试要主动说明这点。
- 树高 h 与节点数 n 的关系：平衡树 h ≈ log n，退化成链 h = n。说空间复杂度时要讲清是 O(h) 而非 O(log n)。

**追问 / 变体**
- **144 前序 / 145 后序**：同一套栈模拟，见上面的改法。
- **BST 的中序是升序**——这是 98、230、530、538 的共同钥匙。
- **迭代器式中序**（173 二叉搜索树迭代器）：把上面的栈存成成员变量，`next()` 弹一个、`hasNext()` 判空。本质是把这段循环"暂停"在中间。
- **N 叉树遍历**（589/590）：栈里压子节点列表，逆序压入。

### 104. 二叉树的最大深度（简单）

**题意**  返回根到最远叶子的节点数。

**暴力**  本题没有"暴力"——递归就是最优解。它的价值在于：这是**分解子问题式**思维的最小样板。

**关键洞察**

「整棵树的最大深度」= 「左右子树最大深度的较大者」+ 1。这一句就是全部。

关键是**信任递归**：写 `depth(node->left)` 时不要在脑子里展开它到底怎么算的，只需相信「它会正确返回左子树的深度」。这种"信任"是所有树形递归的心法——展开去想两层以上，人脑必然过载。

base case：空树深度为 0。这个 0 让叶子节点自动得到 `max(0,0)+1 = 1`，不需要单独写「if 是叶子」的分支。**好的 base case 能消灭特例**。

**最优解（C++）**

```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (!root) return 0;                                  // 空树深度 0
        return max(maxDepth(root->left), maxDepth(root->right)) + 1;
    }
};
```

BFS 版（按层数数，顺带展示层序骨架）：

```cpp
int maxDepth(TreeNode* root) {
    if (!root) return 0;
    queue<TreeNode*> q;
    q.push(root);
    int depth = 0;
    while (!q.empty()) {
        int sz = q.size();                 // 固定本层节点数
        for (int i = 0; i < sz; ++i) {
            TreeNode* node = q.front(); q.pop();
            if (node->left)  q.push(node->left);
            if (node->right) q.push(node->right);
        }
        ++depth;                           // 一层处理完，深度 +1
    }
    return depth;
}
```

**复杂度**  时间 O(n)，空间 O(h)（递归栈）/ BFS O(w)（w 为最大层宽，完全二叉树时约 n/2）。

**边界与坑**
- 空树返回 0，不是 1。
- 单链退化的树递归深度为 n，n 很大时（10⁵ 级）**可能爆栈**。LeetCode 本题 n ≤ 10⁴ 安全，被追问就答「改 BFS 或显式栈」。
- **别和 111 最小深度搞混**：最小深度不能写 `min(left, right) + 1`——只有一个子节点的节点会被算成深度 1，必须特判「某一侧为空时只取另一侧」。这是个经典陷阱：
  ```cpp
  int minDepth(TreeNode* root) {
      if (!root) return 0;
      if (!root->left)  return minDepth(root->right) + 1;   // 必须特判
      if (!root->right) return minDepth(root->left) + 1;
      return min(minDepth(root->left), minDepth(root->right)) + 1;
  }
  ```

**追问 / 变体**
- **111 最小深度**：见上，注意特判。
- **110 平衡二叉树**：在后序位置顺便判 `abs(l - r) <= 1`，用 -1 当"已失衡"的哨兵返回值可做到一次遍历。
- **543 直径**：本题的升级版——把「向上返回的深度」和「答案」分离，见后文。
- **559 N 叉树最大深度**：遍历 children 取 max。

### 226. 翻转二叉树（简单）

**题意**  把二叉树左右镜像翻转，返回根。

**暴力**  先把整棵树序列化/深拷贝成新结构，再按镜像规则重建一棵新树。O(n) 时间但要 O(n) 额外空间，而且完全没必要——**交换指针可以原地完成**，不需要复制任何节点。

**关键洞察**

翻转整棵树 = 交换根的左右孩子 + 递归翻转这两棵子树。三行搞定。

值得注意的是**交换和递归的顺序无所谓**：先 `swap` 再递归（前序），或先递归再 `swap`（后序），结果都对。因为「交换根的两个孩子」和「翻转两棵子树内部」是两件**互不干扰**的事。但**中序位置会错**——先翻左子树，`swap` 之后它跑到了右边，再递归 `node->right` 就把它又翻回去了。这是个很好的检验你是否真理解递归位置的例子。

**最优解（C++）**

```cpp
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (!root) return nullptr;
        swap(root->left, root->right);      // 前序位置：先交换
        invertTree(root->left);
        invertTree(root->right);
        return root;
    }
};
```

迭代版（BFS，避免爆栈）：

```cpp
TreeNode* invertTree(TreeNode* root) {
    if (!root) return nullptr;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        TreeNode* node = q.front(); q.pop();
        swap(node->left, node->right);
        if (node->left)  q.push(node->left);
        if (node->right) q.push(node->right);
    }
    return root;
}
```

**复杂度**  时间 O(n)，空间 O(h) / BFS O(w)。

**边界与坑**
- `swap(root->left, root->right)` 交换的是**指针**，O(1)，不是深拷贝整棵子树。
- **中序位置写会错**（见上），这是本题唯一的思维陷阱。
- 空树返回 `nullptr`，别忘了 base case。
- 返回值必须是 `root`——虽然是原地修改，但函数签名要求返回。

**追问 / 变体**
- **101 对称二叉树**：判断一棵树是否是自己的镜像，见下题。「翻转后是否与原树相同」也可以，但要先深拷贝，不如双指针递归优雅。
- **951 翻转等价二叉树**：允许任意翻转后判等价，递归时试两种匹配。
- 这题因为 Homebrew 作者面试被拒的轶事而出名，实际难度极低。

### 101. 对称二叉树（简单）

**题意**  判断二叉树是否轴对称（关于根的竖直中线镜像）。

**暴力**  翻转一份副本再比较是否相同，O(n) 时间但要 O(n) 额外空间做拷贝。

**关键洞察**

这题的突破口在于**递归对象不是「一个节点」而是「一对节点」**。

「树对称」不能直接分解成「左子树对称 && 右子树对称」——反例：左右子树各自对称但形状不同。正确的分解需要**同时看两个节点**：

`isMirror(a, b)` = `a->val == b->val` && `isMirror(a->left, b->right)` && `isMirror(a->right, b->left)`

注意**交叉比较**：a 的左对 b 的右，a 的右对 b 的左——这个交叉就是"镜像"的数学表达。

base case 要覆盖三种情况：都空（对称，返回 true）、只有一个空（不对称，false）、都不空（比值再递归）。写成 `if (!a || !b) return a == b;` 一行就把前两种合并了——都空时 `nullptr == nullptr` 为 true，一个空时必然 false。

**最优解（C++）**

```cpp
class Solution {
    bool isMirror(TreeNode* a, TreeNode* b) {
        if (!a || !b) return a == b;              // 都空 true；一个空 false
        return a->val == b->val
            && isMirror(a->left, b->right)        // 交叉比较
            && isMirror(a->right, b->left);
    }
public:
    bool isSymmetric(TreeNode* root) {
        return !root || isMirror(root->left, root->right);
    }
};
```

迭代版（队列成对入队）：

```cpp
bool isSymmetric(TreeNode* root) {
    if (!root) return true;
    queue<TreeNode*> q;
    q.push(root->left); q.push(root->right);      // 成对入队
    while (!q.empty()) {
        TreeNode* a = q.front(); q.pop();
        TreeNode* b = q.front(); q.pop();
        if (!a && !b) continue;
        if (!a || !b || a->val != b->val) return false;
        q.push(a->left);  q.push(b->right);       // 依然交叉
        q.push(a->right); q.push(b->left);
    }
    return true;
}
```

**复杂度**  时间 O(n)，空间 O(h) / 迭代 O(w)。

**边界与坑**
- **交叉比较写错是最常见的 bug**：写成 `isMirror(a->left, b->left)` 就变成了「判断两棵树相同」（100 题），不是镜像。
- `if (!a || !b) return a == b;` 这个技巧要理解：它同时处理了"都空"和"单空"。展开写也行，但四行变一行。
- **空节点必须参与比较**。只比较非空节点的值序列会误判：`[1,2,null,3]` 和 `[1,null,2,3]` 的非空中序值序列可能相同但结构不对称。迭代版里 `if (!a && !b) continue;` 就是在维持这一点。
- 只有根节点时返回 true。

**追问 / 变体**
- **100 相同的树**：把交叉改成同侧比较，是本题的兄弟题。
- **572 另一棵树的子树**：对每个节点调用 `isSameTree`，O(nm)；进阶用树哈希或序列化 + KMP 做到 O(n+m)。
- **判断两棵树是否镜像**（不限于同一棵树的左右）：直接调 `isMirror(root1, root2)`。

### 543. 二叉树的直径（简单）

**题意**  返回任意两节点间最长路径的**边数**（路径可以不经过根）。

**暴力**  枚举每个节点作为路径的最高点，计算「左深 + 右深」，每次深度计算都是 O(n) → 总 O(n²)。

**关键洞察**

这是**「返回值 ≠ 答案」模式**的第一道题，务必吃透——124 是它的加权版。

任何一条路径都有唯一的**最高点**（拐点）。以某节点为最高点的路径长度 = `左子树高度 + 右子树高度`（边数）。答案是所有节点这个值的最大值。

暴力的浪费在于反复算高度。而**高度本身就是可以自底向上一次算完的**（104 题）。所以：在计算高度的递归里，**顺便**在后序位置更新全局答案。

这里的关键区分：
- **函数返回**「以本节点为根的子树高度」——这是给父节点用的，父节点只能接一条边下来，所以是 `max(l, r) + 1`。
- **答案记录**「以本节点为拐点的路径长度」`l + r`——这条路径拐了弯，**不能**向上传递给父节点。

搞混这两者是这类题的头号错误。记住一句话：**返回值服务于父节点，答案服务于全局**。

**最优解（C++）**

```cpp
class Solution {
    int best = 0;
    int height(TreeNode* node) {              // 返回：子树高度（边数计）
        if (!node) return 0;
        int l = height(node->left);
        int r = height(node->right);
        best = max(best, l + r);              // 后序位置：以 node 为拐点的路径边数
        return max(l, r) + 1;                 // 向上只能传一条边
    }
public:
    int diameterOfBinaryTree(TreeNode* root) {
        height(root);
        return best;
    }
};
```

**复杂度**  时间 O(n)（每个节点访问一次），空间 O(h)。

**边界与坑**
- **返回 `l + r` 而不是 `max(l,r) + 1` 给父节点**是致命错误——路径拐弯后无法延伸到父节点。
- 题目要的是**边数**不是节点数。用「空节点高度 = 0」的定义时，`l + r` 直接就是边数；如果用「空节点高度 = -1」或者按节点数统计，要相应 `-1`。单节点树答案是 0。
- `best` 初值 0（单节点树的直径就是 0），不能是 `INT_MIN` 后忘了处理空树。
- 直径路径**不一定过根**：`[1,2,3,4,5]` 中最长路径可能在某棵子树内部。用暴力思路"从根出发"必错。

**追问 / 变体**
- **124 最大路径和**：把「高度」换成「路径和」，并加上「负数贡献取 0」的剪枝，是本题的直接升级，见后文。
- **687 最长同值路径**：只有 `node->val == child->val` 时才能延伸。
- **返回直径路径本身**：记录拐点节点，再从拐点向两侧各走最深路径。
- **N 叉树直径**：取所有子树高度中**最大的两个**相加。

### 102. 二叉树的层序遍历（中等）

**题意**  逐层返回节点值，每层一个数组。

**暴力**  先求树高 h，然后对每一层 `d` 单独做一次 DFS 只收集深度等于 `d` 的节点，O(nh)（退化成链时 O(n²)）。浪费在于**同一批节点被重复访问了 h 次**——而一次遍历本来就能顺路知道每个节点在哪一层。

**关键洞察**

BFS 天然按层推进，但普通 BFS 的队列里**会混着两层的节点**，所以要解决「怎么知道一层到哪结束」。

最干净的答案：**进入循环体时先记下 `q.size()`，这就是当前层的节点数**。因为此刻队列里恰好只有本层节点（上一层已全部弹出，下一层还没开始入队）。然后固定跑这么多次，期间新入队的都属于下一层。

```cpp
int sz = q.size();                      // 快照：本层节点数
for (int i = 0; i < sz; ++i) { ... }    // 只处理本层
```

**必须先存到变量**——直接写 `for (int i = 0; i < q.size(); ++i)` 会因为循环体内 `q.push` 让 `q.size()` 不断变大而彻底跑偏。这是 BFS 分层的头号 bug。

**最优解（C++）**

```cpp
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        vector<vector<int>> ans;
        if (!root) return ans;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            int sz = q.size();                    // 关键：先固定本层大小
            vector<int> level;
            level.reserve(sz);
            for (int i = 0; i < sz; ++i) {
                TreeNode* node = q.front(); q.pop();
                level.push_back(node->val);
                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
            ans.push_back(move(level));
        }
        return ans;
    }
};
```

DFS 版（用深度当下标，说明层序不一定要用队列）：

```cpp
void dfs(TreeNode* node, int depth, vector<vector<int>>& ans) {
    if (!node) return;
    if (depth == (int)ans.size()) ans.push_back({});   // 第一次到这一层，开新桶
    ans[depth].push_back(node->val);
    dfs(node->left,  depth + 1, ans);
    dfs(node->right, depth + 1, ans);
}
```

**复杂度**  时间 O(n)，空间 O(w)（w 为最大层宽）；DFS 版栈空间 O(h)。

**边界与坑**
- **`sz` 必须提前存**，见上。
- 空树返回空 `vector`，不是 `{{}}`。
- 入队前判非空（`if (node->left)`），否则队列里塞进 `nullptr` 后 `node->val` 崩。另一种流派是允许 `nullptr` 入队再在出队时跳过，但那样 `q.size()` 就不等于真实层宽了，分层会出错。
- DFS 版的 `depth == ans.size()` 判断依赖**前序遍历顺序**（先左后右），保证每层第一次被访问时才新建桶。

**追问 / 变体**
- **107 自底向上层序**：结果 `reverse`，或用 `deque` 头插。
- **103 锯齿形层序**：奇数层 `reverse(level)`，或用 `deque` 按方向两端插入。
- **199 右视图**：每层取最后一个，见下题。
- **515 每层最大值 / 637 每层平均值**：本模板换个统计口即可。
- **116/117 填充右侧指针**：在层内把 `q.front()` 连成链。

### 108. 将有序数组转换为二叉搜索树（简单）

**题意**  把升序数组转成一棵**高度平衡**的 BST（任意节点左右子树高度差 ≤ 1）。答案不唯一。

**暴力**  按数组顺序依次 `insert` 到一棵普通 BST 里。结果**必然退化成一条右斜链**（因为每个新元素都比已有的都大），高度 O(n)，完全不满足平衡要求。**这个失败正说明"插入顺序决定树形"，而平衡要求逼着我们从中间开始插。**

**关键洞察**

两个约束各自对应一个决策：

- **BST 要求**：中序遍历必须是原数组顺序 → 选定某个元素当根后，它左边的元素**只能**全在左子树，右边的**只能**全在右子树。
- **平衡要求**：左右子树节点数要尽量相等 → 根必须取**中间元素**。

两个约束一合并，答案就唯一确定了：**取中点当根，左半段递归建左子树，右半段递归建右子树**。这其实就是二分查找的递归树结构——所以天然平衡，高度 O(log n)。

这是**「分治建树」**的模板题：函数处理一个区间 `[l, r]`，`l > r` 表示空区间返回 `nullptr`。

**最优解（C++）**

```cpp
class Solution {
    TreeNode* build(vector<int>& a, int l, int r) {
        if (l > r) return nullptr;                 // 空区间
        int m = l + (r - l) / 2;                   // 取中点（偏左），防溢出写法
        TreeNode* root = new TreeNode(a[m]);
        root->left  = build(a, l, m - 1);
        root->right = build(a, m + 1, r);
        return root;
    }
public:
    TreeNode* sortedArrayToBST(vector<int>& nums) {
        return build(nums, 0, (int)nums.size() - 1);
    }
};
```

**复杂度**  时间 O(n)（每个元素建一个节点），空间 O(log n) 递归栈（输出树本身 O(n) 不计入）。

**边界与坑**
- **`(int)nums.size() - 1` 的强转不能省**。`size()` 返回 `size_t`，空数组时 `size() - 1` 是 `SIZE_MAX`，传给 `int` 参数是实现定义行为。虽然本题保证 `n >= 1`，但这个习惯要养成。
- `m = l + (r - l) / 2` 比 `(l + r) / 2` 安全（后者在 `l + r` 超过 `INT_MAX` 时溢出）。本题 n 小无所谓，但和二分专题保持同一套写法更省脑子。
- 取 `m = l + (r - l + 1) / 2`（偏右中点）也能得到合法答案，只是树形不同。**LeetCode 对本题接受任意平衡答案**，但如果判题要求精确匹配某棵树，就得对准题目示例用的是哪个中点。
- 别写成「先建左子树再 `new` 根」——顺序无所谓，但要保证每个元素只用一次。

**追问 / 变体**
- **109 有序链表转 BST**：链表不能 O(1) 随机访问。两种做法：① 先转成数组（O(n) 空间）；② 快慢指针找中点，O(n log n)；③ **中序模拟法**——先算出长度，按中序顺序递归时同步推进链表指针，O(n) 时间 O(log n) 空间，是最优雅的解。
- **验证结果是否平衡**（110）：可以拿来自测。
- **1382 将 BST 变平衡**：先中序拍平成数组，再套本题。

### 98. 验证二叉搜索树（中等）

**题意**  判断是否为合法 BST：**任意**节点的左子树所有值 < 它 < 右子树所有值。

**暴力（错误解法，必须知道为什么错）**

```cpp
// ✗ 错误！只比较了父子，没约束整棵子树
bool isValidBST(TreeNode* root) {
    if (!root) return true;
    if (root->left  && root->left->val  >= root->val) return false;
    if (root->right && root->right->val <= root->val) return false;
    return isValidBST(root->left) && isValidBST(root->right);
}
```

反例：`[5, 1, 6, null, null, 3, 7]`。节点 3 是 6 的左孩子（3 < 6 ✓），但 3 在**根 5 的右子树**里，却比 5 小 → 非法。这个错解能通过大量测试用例，是本题最经典的坑：**BST 的约束是全局的，不是局部父子关系**。

**关键洞察**

有两条正路，都值得会：

**思路一：上下界（自上而下传约束）**

每个节点其实活在一个**开区间** `(lo, hi)` 里。递归时把约束往下传：
- 走进左子树，上界收紧为当前节点值 → `(lo, node->val)`
- 走进右子树，下界收紧为当前节点值 → `(node->val, hi)`

这样节点 3 会带着 `(5, 6)` 的约束进去，`3 <= 5` 立刻判非法。**这才是把"祖先的约束"真正传下去了**。

**思路二：中序必须严格递增**

BST 的中序遍历是升序序列。所以只需中序走一遍，检查每个值都 **严格大于**前一个值。这个思路更短，而且顺带复习了中序模板。

**最优解（C++，上下界法）**

```cpp
class Solution {
    bool check(TreeNode* node, long long lo, long long hi) {
        if (!node) return true;
        if (node->val <= lo || node->val >= hi) return false;   // 严格不等
        return check(node->left,  lo, node->val)                // 左：收紧上界
            && check(node->right, node->val, hi);               // 右：收紧下界
    }
public:
    bool isValidBST(TreeNode* root) {
        return check(root, LLONG_MIN, LLONG_MAX);
    }
};
```

**中序法（推荐面试写，更短且不需要 `long long` 技巧）**

```cpp
class Solution {
public:
    bool isValidBST(TreeNode* root) {
        stack<TreeNode*> st;
        TreeNode* cur = root;
        TreeNode* prev = nullptr;              // 用指针而非数值，天然避开 INT_MIN 问题
        while (cur || !st.empty()) {
            while (cur) { st.push(cur); cur = cur->left; }
            cur = st.top(); st.pop();
            if (prev && prev->val >= cur->val) return false;   // 中序必须严格递增
            prev = cur;
            cur = cur->right;
        }
        return true;
    }
};
```

**复杂度**  时间 O(n)，空间 O(h)。

**边界与坑**
- **局部父子比较是错的**，见上文反例。这是本题的核心考点。
- **必须严格不等**（`<=` / `>=` 判非法）。BST 定义不允许重复值，`[2,2,2]` 是非法的。用 `<` 会放过重复值。
- **上下界要用 `long long`**。节点值可以是 `INT_MIN` / `INT_MAX`，用 `INT_MIN`/`INT_MAX` 当初始界会让 `root->val <= INT_MIN` 在根节点就是 `INT_MIN` 时误判为非法。单节点树 `[-2147483648]` 就是这个 hack 测试用例。中序法用 `prev` **指针**判空，从根本上绕过了这个问题——这是它比上下界法优越的一点。
- 中序法里 `prev` 要在弹栈后更新，别写在压栈时。
- 空树是合法 BST，返回 true。

**追问 / 变体**
- **530 / 783 BST 最小绝对差**：同样是中序 + `prev`，改成统计 `min(cur->val - prev->val)`。
- **230 第 K 小**：中序走到第 K 个，见下题。
- **99 恢复二叉搜索树**：中序找出**两个**逆序对位置再交换，是本题的进阶。
- **允许重复值的 BST**：把 `>=` 改成 `>`，并明确重复值放左还是放右。
- **1373 BST 子树最大和**：需要在后序位置同时返回「是否合法 + 区间 + 和」，是"多返回值"递归的练习。

### 230. 二叉搜索树中第 K 小的元素（中等）

**题意**  返回 BST 中第 k 小的值（k 从 1 开始）。

**暴力**  中序遍历全部存进数组，返回 `a[k-1]`。O(n) 时间 O(n) 空间——能过，但没利用「只要第 k 个」这个条件。

**关键洞察**

**BST 的中序遍历就是升序序列**，所以「第 k 小」= 「中序遍历的第 k 个」。

优化点在于**提前退出**：不需要遍历完整棵树，数到第 k 个就返回。这里**迭代版的中序比递归版更自然**——递归想中途返回需要额外的标志变量或异常，而迭代版直接 `return` 就行。这是少见的"迭代比递归更好写"的场景。

时间复杂度变成 O(h + k)：先花 O(h) 走到最左下角，然后每弹一次栈得到一个元素，共 k 次。k 很小时远优于 O(n)。

**最优解（C++）**

```cpp
class Solution {
public:
    int kthSmallest(TreeNode* root, int k) {
        stack<TreeNode*> st;
        TreeNode* cur = root;
        while (cur || !st.empty()) {
            while (cur) { st.push(cur); cur = cur->left; }
            cur = st.top(); st.pop();
            if (--k == 0) return cur->val;      // 中序第 k 个，立即返回
            cur = cur->right;
        }
        return -1;                              // 题目保证 k 合法，不会到这
    }
};
```

递归版（用成员变量 + 提前剪枝）：

```cpp
class Solution {
    int cnt, ans;
    void dfs(TreeNode* node) {
        if (!node || cnt == 0) return;          // cnt == 0 表示已找到，剪掉后续
        dfs(node->left);
        if (--cnt == 0) { ans = node->val; return; }
        dfs(node->right);
    }
public:
    int kthSmallest(TreeNode* root, int k) {
        cnt = k;
        dfs(root);
        return ans;
    }
};
```

**复杂度**  时间 O(h + k)，空间 O(h)。若树平衡且 k 小，接近 O(log n)。

**边界与坑**
- **k 从 1 开始计数**，不是 0。`--k == 0` 的写法（先减后判）正好对齐：第一个元素时 k 由 1 变 0。写成 `k-- == 0` 就错位了。
- 递归版**必须有 `cnt == 0` 的剪枝**，否则找到之后还会继续遍历右子树，把 `ans` 覆盖掉（如果不小心又写了赋值）或者白跑一遍。
- 不要试图用「左子树大小 = 根的排名 - 1」在没有额外信息的裸 BST 上做二分——**裸 BST 节点里没存子树大小**，硬算 size 是 O(n)，反而更慢。
- 迭代版末尾的 `return -1` 是为了让编译器闭嘴；题目保证 `1 <= k <= n`。

**追问 / 变体**
- **官方追问：如果 BST 频繁被修改，且要频繁查第 k 小，如何优化？**  这是本题真正的考点。答案：给每个节点**增维**存 `size`（子树节点数），查第 k 小时在 O(h) 内定位——
  ```
  在节点 node：设 ls = size(node->left)
    若 k == ls + 1 → 答案就是 node->val
    若 k <= ls     → 去左子树找第 k 小
    否则           → 去右子树找第 (k - ls - 1) 小
  ```
  插入/删除时沿路更新 `size`，配合 AVL / 红黑树维持平衡即得 O(log n)。这种结构叫**顺序统计树（order-statistic tree）**。
- **第 k 大**：改成「右 → 根 → 左」的反中序。
- **无序数组第 k 大**（215）：用堆或快速选择，见 [13-堆](13-堆.md)。
- **树状数组 / 线段树**做动态第 k 小：值域较小时的另一条路。

### 199. 二叉树的右视图（中等）

**题意**  从右侧看这棵树，返回每层最右边的节点值（自上而下）。

**暴力**  先跑一遍 102 的完整层序遍历拿到所有层，再取每层的最后一个元素。O(n) 时间但要 O(n) 空间存下所有节点值——正确且思路最短，**面试可以先说这个**。下面的写法只是把"存整层再取最后一个"优化成"只留最后一个"。

**关键洞察**

「右视图」= **每一层最右边的那个节点**。注意不是「一直往右走的那条链」——如果右子树某处断了，左子树更深的节点会露出来。举例：`[1,2,3,4]`（4 是 2 的左孩子），第三层只有 4，所以答案是 `[1,3,4]`，而"一路向右"会得到 `[1,3]`，漏掉 4。想清这一点，题就变成了 102 的变形。

**两种实现，各有巧妙处**：

1. **BFS**：套 102 的分层模板，`i == sz - 1` 时收集。直白。
2. **DFS 先右后左**：按「根 → 右 → 左」的顺序遍历，那么**每一层第一个被访问到的节点就是该层最右节点**。用 `depth == ans.size()` 判断「这一层是否第一次到达」。这个写法很短，也是判断「某深度首次访问」这个技巧的经典应用。

**最优解（C++，BFS）**

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> ans;
        if (!root) return ans;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            int sz = q.size();
            for (int i = 0; i < sz; ++i) {
                TreeNode* node = q.front(); q.pop();
                if (i == sz - 1) ans.push_back(node->val);   // 本层最后一个
                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
        }
        return ans;
    }
};
```

**DFS 版（先右后左）**

```cpp
class Solution {
    void dfs(TreeNode* node, int depth, vector<int>& ans) {
        if (!node) return;
        if (depth == (int)ans.size()) ans.push_back(node->val);  // 该层首次到达
        dfs(node->right, depth + 1, ans);      // 关键：先右
        dfs(node->left,  depth + 1, ans);
    }
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> ans;
        dfs(root, 0, ans);
        return ans;
    }
};
```

**复杂度**  时间 O(n)，空间 BFS O(w) / DFS O(h)。

**边界与坑**
- **不是"一路向右"**，见上文反例。这是本题唯一的思维陷阱，也是面试官爱设的陷阱数据。
- BFS 版 `sz` 要提前存（同 102）。
- DFS 版**必须先递归右子树**。写成先左后右就变成了左视图。
- DFS 版的 `depth == ans.size()` 依赖 `ans` 恰好按层增长，所以不能预先 `resize` 或者跳层。
- 空树返回空数组。

**追问 / 变体**
- **左视图**：BFS 取 `i == 0`，或 DFS 先左后右。
- **俯视图 / 底视图**（314 垂序遍历、987）：按「列坐标」分组而非按层，需要 `map<int, vector<int>>` 按 x 排序。
- **515 每层最大值**：同一个分层模板换统计口。
- **1161 最大层内元素和**：同上。

### 114. 二叉树展开为链表（中等）

**题意**  原地把二叉树展开成单链表：所有 `left` 置空，`right` 串成链，顺序与**前序遍历**一致。

**暴力**  先前序遍历存进 `vector`，再遍历数组重新连接。O(n) 时间 O(n) 空间，思路清晰，面试可以先给这个。

**关键洞察**

想做到 O(1) 额外空间，不能先收集再连接，必须**边走边接**。

观察展开后的结构：节点 `cur` 后面紧跟的是它**左子树的前序序列**，再之后才是右子树。所以对每个有左子树的节点：

1. 找到左子树的**最右节点** `pre`——它是左子树前序序列的**最后一个**节点（左子树内一路向右走到底）。
2. 把 `cur` 的右子树整体挂到 `pre->right`。
3. 把左子树移到 `cur->right`，`cur->left = nullptr`。
4. `cur = cur->right` 继续（此时进入的是原左子树的根）。

这样每一步都保持「已处理部分是正确的前序链」，而且**不需要栈**——因为要接回的位置总能从左子树内部找到。这个「找左子树最右节点」的手法和 94 的 Morris 遍历是同一个内核，值得连起来记。

**最优解（C++）**

```cpp
class Solution {
public:
    void flatten(TreeNode* root) {
        TreeNode* cur = root;
        while (cur) {
            if (cur->left) {
                TreeNode* pre = cur->left;
                while (pre->right) pre = pre->right;   // 左子树最右节点 = 左子树前序的末尾
                pre->right = cur->right;               // 原右子树接到它后面
                cur->right = cur->left;                // 左子树上提为右子树
                cur->left  = nullptr;
            }
            cur = cur->right;                          // 前进（进入原左子树）
        }
    }
};
```

递归版（后序思路，O(h) 栈空间，但更好想）：

```cpp
void flatten(TreeNode* root) {
    if (!root) return;
    flatten(root->left);
    flatten(root->right);
    TreeNode* l = root->left, *r = root->right;        // 此时两边都已是链
    root->left = nullptr;
    root->right = l;
    TreeNode* p = root;
    while (p->right) p = p->right;                     // 走到左链末尾
    p->right = r;
}
```

**复杂度**  迭代版时间 O(n)（每条边最多被走两次：一次找 `pre`，一次前进），空间 **O(1)**；递归版时间 O(n)，空间 O(h)。

**边界与坑**
- **`while (pre->right)` 不能写成 `while (pre->right && pre->right != cur)`**——那是 Morris 遍历的写法（要防线索成环）。本题每步都把 `left` 清空且结构真的被改造，不会形成回指，多写这个条件反而让人困惑。
- **三步赋值的顺序不能乱**：必须先 `pre->right = cur->right` 保存原右子树，再覆盖 `cur->right`。反过来写会丢掉整棵右子树。
- **`cur->left = nullptr` 不能忘**。题目明确要求所有左指针为空，忘了会判错。
- 递归版里必须**先把 `l`、`r` 存到局部变量**再改指针，否则改完 `root->right` 就找不到原右子树了。
- 空树直接返回，不要访问 `root->left`。
- 函数返回 `void`——原地修改，别新建节点（新建也能过，但违背"展开"的题意，面试会被追问）。

**追问 / 变体**
- **按中序 / 后序展开**：中序展开就是 897 递增顺序搜索树，用 Morris 中序改造。
- **展开成双向链表**（426 BST 转排序双向链表）：中序遍历 + 维护 `prev` 指针，左右指针都要接。
- **还原**：展开后信息已丢失（无法区分原来是左孩子还是右孩子的独子），不可逆。
- **N 叉树展开**（430 扁平化多级双向链表）：同样的"找末尾再接"思路。

### 105. 从前序与中序遍历序列构造二叉树（中等）

**题意**  给出前序和中序遍历序列（**元素互不重复**），重建这棵二叉树。

**暴力**  同样是"前序定根、中序分界"的递归，但**每层都用 `find` 线性扫描中序数组**去定位根的位置，且**每层都拷贝出新的子数组**切片。时间 O(n²)（退化成链时每层扫 O(n)）、空间 O(n²)（切片拷贝）。两处浪费都能消掉：**位置查找换成哈希表 O(1)，数组切片换成下标区间 O(1)**。

**关键洞察**

两个序列各提供一半信息，合起来才能唯一确定树：

- **前序** `[根 | 左子树前序 | 右子树前序]` → **第一个元素就是根**。
- **中序** `[左子树中序 | 根 | 右子树中序]` → 找到根的位置后，**左边全是左子树，右边全是右子树**，于是得到左子树的**节点个数**。

有了左子树大小 `leftLen`，就能把前序序列也切成两段（前序里根之后紧跟的 `leftLen` 个元素是左子树），于是递归的四个边界全部确定。这就是全部思路：**前序定根，中序定分界**。

两个工程要点：

1. **用哈希表预存「中序值 → 下标」**，把每层找根位置从 O(n) 降到 O(1)，总复杂度 O(n²) → O(n)。这一步是本题从"能过"到"最优"的关键。
2. **传下标区间而不是切数组**。每层 `vector` 切片会带来 O(n) 拷贝和 O(n²) 空间，用 `[pl, pr]` / `[il, ir]` 四个下标是标准做法。

边界推导（容易写错，建议在纸上用 `pre=[3,9,20,15,7]`, `in=[9,3,15,20,7]` 走一遍）：

```
leftLen = m - il                       // m 是根在中序里的下标
左子树： 前序 [pl+1, pl+leftLen]        中序 [il, m-1]
右子树： 前序 [pl+leftLen+1, pr]        中序 [m+1, ir]
```

**最优解（C++）**

```cpp
class Solution {
    unordered_map<int, int> pos;                       // 中序：值 -> 下标
    TreeNode* build(vector<int>& pre, int pl, int pr, int il, int ir) {
        if (pl > pr) return nullptr;                   // 空区间
        int m = pos[pre[pl]];                          // 根在中序里的位置
        int leftLen = m - il;                          // 左子树节点数
        TreeNode* root = new TreeNode(pre[pl]);
        root->left  = build(pre, pl + 1, pl + leftLen, il, m - 1);
        root->right = build(pre, pl + leftLen + 1, pr, m + 1, ir);
        return root;
    }
public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        for (int i = 0; i < (int)inorder.size(); ++i) pos[inorder[i]] = i;
        return build(preorder, 0, (int)preorder.size() - 1, 0, (int)inorder.size() - 1);
    }
};
```

**复杂度**  时间 O(n)（每个节点建一次，找根 O(1)），空间 O(n)（哈希表 + 递归栈，最坏 O(n)）。

**边界与坑**
- **`leftLen` 必须用中序算**（`m - il`），不能用 `m` 本身——`il` 不为 0 时（子问题里）`m` 是全局下标，直接用会算出错误的长度。这是本题最高频的 bug。
- **前序右子树的起点是 `pl + leftLen + 1`**，那个 `+1` 是跳过根。少写就会把根重复用一次，多写会漏节点。
- **必须强转 `(int)size()`**：空数组时 `size() - 1` 是 `size_t` 的巨大值。
- **本题依赖「值互不重复」**。有重复值时 `pos` 会被覆盖，树无法唯一确定——面试被问「有重复值怎么办」，正确答案是**无解/不唯一**，除非额外给出结构信息。
- 递归终止只需判 `pl > pr`，不需要同时判 `il > ir`（两个区间长度恒等）。
- 前序 + 后序**不能**唯一确定二叉树（无法区分只有一个孩子时它是左还是右）；能唯一确定的组合是「前序 + 中序」和「后序 + 中序」。这是常见考点。

**追问 / 变体**
- **106 从中序与后序构造**：后序的**最后一个**是根，其余推导对称。
- **889 从前序与后序构造**（满二叉树）：只有在"每个节点 0 或 2 个孩子"时才唯一。
- **不用哈希表的 O(n) 解法**：用栈模拟前序下降过程，或用「上界」参数的递归写法（`build(pre, in, &pi, &ii, stop)`），空间更省，是进阶写法。
- **验证**：重建后跑一遍前序/中序对比原数组，是很好的自测手段。

### 437. 路径总和 III（中等）

**题意**  统计路径和等于 `targetSum` 的路径数目。路径**必须向下**（父 → 子方向），但**不必从根开始、也不必到叶子结束**。

**暴力**  以每个节点为起点，向下 DFS 累加，看有多少条路径达标：

```cpp
class Solution {
    int countFrom(TreeNode* node, long long rest) {     // 从 node 出发、必须以 node 开头
        if (!node) return 0;
        rest -= node->val;
        return (rest == 0) + countFrom(node->left, rest) + countFrom(node->right, rest);
    }
public:
    int pathSum(TreeNode* root, int targetSum) {
        if (!root) return 0;
        return countFrom(root, targetSum)               // 以 root 开头的
             + pathSum(root->left, targetSum)           // 起点在左子树的
             + pathSum(root->right, targetSum);         // 起点在右子树的
    }
};
```

O(n²)（链状树时每个起点走 O(n)），n ≤ 1000 能过。**注意 `rest == 0` 后不能停**——后面可能还有正负相消的路径。

浪费在哪：从根到某节点这条链，被反复重新累加了很多次。

**关键洞察**

「向下的连续路径和」在一条**根到当前节点的链**上，本质就是**子数组和**问题——而子数组和 = 两个前缀和之差。于是可以直接搬 [560 和为 K 的子数组](04-子串.md) 的**前缀和 + 哈希表**套路：

设 `cur` = 根到当前节点的前缀和。以当前节点**结尾**的达标路径，其起点祖先 `a` 满足

```
cur - prefix(a) == target   →   prefix(a) == cur - target
```

所以只要用哈希表记录**当前这条根到节点的链上**，每个前缀和出现了多少次，查一下 `cnt[cur - target]` 就得到以当前节点结尾的路径数。

与 560 的唯一区别是**树上要回溯**：哈希表必须只包含「当前链」上的前缀和。所以在离开一个节点时，要把它的贡献 `--cnt[cur]` 撤销。**忘记回溯就会把兄弟分支的前缀和错误地当成祖先**，答案偏大——这是本题头号 bug。

`cnt[0] = 1` 的初始化对应「空前缀」，处理**从根开始**的路径。

**最优解（C++）**

```cpp
class Solution {
    unordered_map<long long, int> cnt;      // 当前链上：前缀和 -> 出现次数
    int target, ans = 0;
    void dfs(TreeNode* node, long long cur) {
        if (!node) return;
        cur += node->val;
        auto it = cnt.find(cur - target);   // 用 find 而非 [] ，避免插入无用的 0 项
        if (it != cnt.end()) ans += it->second;
        ++cnt[cur];                         // 进入：把自己加入当前链
        dfs(node->left,  cur);
        dfs(node->right, cur);
        --cnt[cur];                         // 回溯：离开这条链，撤销贡献
    }
public:
    int pathSum(TreeNode* root, int targetSum) {
        target = targetSum;
        cnt[0] = 1;                         // 空前缀，让"从根开始"的路径被计数
        dfs(root, 0);
        return ans;
    }
};
```

**复杂度**  时间 O(n)（每个节点常数次哈希操作），空间 O(h)。相比暴力的 O(n²) 是质的提升。

**边界与坑**
- **`--cnt[cur]` 的回溯不能漏**，也不能写在 `dfs` 两个子调用之间。
- **前缀和必须用 `long long`**。本题 `Node.val` 可达 ±10⁹，节点数 1000 → 前缀和可达 ±10¹²，`int` 必溢出。这是本题第二大坑，而且用 `int` 时小数据全对、大数据才错，很难查。
- **查询必须在 `++cnt[cur]` 之前**。反过来的话，当 `target == 0` 时会把「当前节点自己形成的空路径」算进去，多计数。
- `ans += it->second` 里累加的是**次数**不是 1——同一个前缀和可能在链上出现多次（有正有负时），每次都对应一条不同的路径。
- 值可以为负、`targetSum` 可以为负，所以**不能做「和已超过 target 就剪枝」的优化**。
- 用 `ans += cnt[cur - target]` 也对，但 `operator[]` 会为不存在的 key 插入 0 项，白占空间还污染表（不影响正确性，因为计数为 0）。
- 空树返回 0。

**追问 / 变体**
- **112 路径总和**（是否存在根到叶的路径）/ **113 路径总和 II**（返回所有根到叶路径）：约束更强（必须根到叶），用普通回溯即可，反而更简单。
- **560 和为 K 的子数组**：本题的数组版，前缀和套路的原型，见 [04-子串](04-子串.md)。
- **路径可以拐弯**（不限向下）：那就是 124 的形态，前缀和法失效。
- **求路径本身而非计数**：哈希表要改存前缀和 → 节点列表，空间变大。
- **必须以叶子结尾但不必从根开始**：加一个"是否叶子"的判断即可。

### 236. 二叉树的最近公共祖先（中等）

**题意**  给定两个**保证存在**的节点 `p`、`q`，返回它们最深的公共祖先（一个节点可以是自己的祖先）。

**暴力**  先各自求出「根 → p」和「根 → q」的路径（用父指针哈希表或 DFS 记录），再比较两条路径最后一个相同的节点。O(n) 时间 O(n) 空间，思路直白，是**允许存父指针时的标准解**：

```cpp
// 思路：记录每个节点的父指针，从 p 一路向上标记祖先，再从 q 向上找第一个被标记的
```

为什么不够优雅：需要额外的哈希表和两次遍历，没利用「递归天然自底向上汇总」的能力。

**关键洞察**

用**后序位置汇总**：递归函数 `lca(root, p, q)` 的语义定义为——

> 如果子树里含有 p 或 q，返回「这棵子树内的 LCA，或者找到的那个节点」；都不含则返回 `nullptr`。

在后序位置拿到左右两侧的结果 `l`、`r`，只有三种情况：

- **`l && r`**：p、q 分别在两侧 → **当前节点就是 LCA**。
- **只有一侧非空**：两个目标都在那一侧（或只找到一个）→ 把那一侧的结果**原样上传**。
- **都为空**：本子树无关 → 返回 `nullptr`。

而 base case `if (root == p || root == q) return root;` 是精妙之处：**找到目标就立刻返回，不再往下找**。这自动处理了「p 是 q 的祖先」这一情形——此时在 p 处就返回 p，上层看到「只有一侧非空」于是一路上传 p，最终答案正是 p。**不需要任何特判**。

这个"三分支 + 提前返回"是本题的全部，代码只有五行，但每一行都不能动。

**最优解（C++）**

```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (!root || root == p || root == q) return root;   // 空 或 命中目标，立即返回
        TreeNode* l = lowestCommonAncestor(root->left,  p, q);
        TreeNode* r = lowestCommonAncestor(root->right, p, q);
        if (l && r) return root;                            // 分居两侧 → 当前就是 LCA
        return l ? l : r;                                   // 否则上传非空的那一侧
    }
};
```

**复杂度**  时间 O(n)（每个节点最多访问一次），空间 O(h) 递归栈。

**边界与坑**
- **本解法的正确性依赖「p、q 一定存在」**。如果不保证存在，`[1,2]` 查 `lca(2, 5)` 会返回 2（因为在 2 处命中就返回了），但正确答案应是 `nullptr`。**这是本题最重要的追问**，解决办法是加两个布尔标记，遍历完整棵树后确认两者都找到了：
  ```cpp
  bool foundP = false, foundQ = false;
  TreeNode* dfs(TreeNode* root, TreeNode* p, TreeNode* q) {
      if (!root) return nullptr;
      TreeNode* l = dfs(root->left, p, q);
      TreeNode* r = dfs(root->right, p, q);
      if (root == p) { foundP = true; return root; }   // 注意：先递归再判，不提前返回
      if (root == q) { foundQ = true; return root; }
      if (l && r) return root;
      return l ? l : r;
  }
  // 最后： return (foundP && foundQ) ? result : nullptr;
  ```
  区别在于**不能提前返回**，必须把整棵树走完才知道两个节点是否都存在。
- **比较用指针 `==` 而不是 `val`**。题目给的是节点指针；值相等的不同节点会导致错误（虽然本题保证值唯一）。
- `return l ? l : r;` 已覆盖「都为空返回 nullptr」，不用再写一个分支。
- 别在前序位置判 `l && r`——那时还没有子树信息。本题**必须**在后序位置汇总。
- 一个节点可以是自己的祖先，所以 `lca(p, p) == p`，本代码天然正确。

**追问 / 变体**
- **235 BST 的 LCA**：利用有序性，`p->val` 和 `q->val` 都小于当前值就往左，都大于就往右，否则当前节点即答案。O(h) 且不需递归遍历整树。
- **1650 有父指针的 LCA**：转化成「[两条链表求交点](07-链表.md)」（160 题），双指针互换即可，O(1) 空间。
- **不保证节点存在**：见上文标记法。
- **多次查询同一棵树**：预处理**倍增（binary lifting）** 或 **欧拉序 + 稀疏表 RMQ**，做到 O(log n) / O(1) 单次查询，是竞赛与大规模系统的标准做法。
- **N 叉树 LCA**（1123 最深叶节点的 LCA 类）：统计非空返回值个数 ≥ 2 即为答案。

### 124. 二叉树中的最大路径和（困难）

**题意**  路径 = 任意节点序列，相邻节点间有边，**每个节点最多出现一次**，且**不必经过根**。求最大节点值之和。节点值可为负。

**暴力**  枚举每个节点作为路径最高点，向左右各求一条「最大向下路径和」，每次都重新递归 → O(n²)。

**关键洞察**

这题是 **543 直径的加权版**，两个核心技巧：

**技巧一：返回值 ≠ 答案（同 543）**

每条路径有唯一**最高点（拐点）**。以 `node` 为拐点的最大路径和 = `node->val + 左边最大向下贡献 + 右边最大向下贡献`。这条路径**拐了弯，不能再向上延伸**，所以它只能用来更新全局答案，不能作为返回值。

返回给父节点的必须是「从 `node` 出发一路向下的单边最大和」= `node->val + max(左贡献, 右贡献)`。

**技巧二：负贡献直接归零**

因为值可以为负，某一侧的最大向下和可能是负数。这时**不走那一侧**永远不劣——所以取

```cpp
int l = max(gain(node->left), 0);
```

`max(..., 0)` 的语义是「这一侧要么带来正收益，要么干脆不选（贡献 0）」。这一个 `max` 同时解决了两件事：剪掉负分支，以及让空节点返回 0 变得合理。

**为什么答案初值必须是 `INT_MIN`**：所有节点都是负数时（如 `[-3]`），答案是 -3 而不是 0。路径**至少包含一个节点**，不能为空。如果初值写 0，`[-3]` 会错答 0。这是本题最经典的错误。

注意区分：**「向下贡献」允许取 0（可以不选子树）**，但**「答案」不能取 0（必须选至少一个节点）**。这两个 0 的含义完全不同，想清楚了这题就通了。

**最优解（C++）**

```cpp
class Solution {
    int best = INT_MIN;
    int gain(TreeNode* node) {                  // 返回：从 node 向下延伸的单边最大和
        if (!node) return 0;
        int l = max(gain(node->left),  0);      // 负贡献丢弃 = 不走这一侧
        int r = max(gain(node->right), 0);
        best = max(best, node->val + l + r);    // 后序：以 node 为拐点的完整路径
        return node->val + max(l, r);           // 向上只能提供一条边
    }
public:
    int maxPathSum(TreeNode* root) {
        gain(root);
        return best;
    }
};
```

**复杂度**  时间 O(n)，空间 O(h)。

**边界与坑**
- **`best` 初值必须 `INT_MIN`**，不能是 0。测试用例 `[-3]` 专门卡这个。
- **返回值是 `node->val + max(l, r)`，不是 `node->val + l + r`**。返回拐点值给父节点，会造出「一个节点出现两次」的非法路径——这是本题最致命的逻辑错误，而且小数据往往仍能过。
- **`max(gain(...), 0)` 的 0 不能省**。全负树里不剪负分支会算出更小的值。
- **返回值不要也 `max(..., 0)`**。写成 `return max(node->val + max(l,r), 0)` 就丢失了「路径至少含当前节点」的语义，会让上层误认为可以从这里获得 0 收益，导致全负树答案错成 0。**该归零的是子树贡献，不是自己**。
- `node->val + l + r` 理论上可能溢出 `int`：本题 `|val| <= 1000`、节点数 ≤ 3×10⁴，最大 3×10⁷，安全。若约束放大到 10⁹ 级就要用 `long long`。
- 单节点树返回该节点值。空树题目保证不出现（`n >= 1`）。

**追问 / 变体**
- **543 直径**：把「和」换成「边数」，去掉负数处理，是本题的简化版。
- **687 最长同值路径**：加上 `val` 相等的条件才允许延伸。
- **路径必须从根开始**：退化成简单递归 `max(l, r) + val`，不需要拐点逻辑。
- **返回路径本身**：记录最优拐点，再从拐点向两侧回溯最大贡献链。
- **允许节点重复访问**：问题变成图上最长路径，NP-hard。
- **N 叉树版**：取所有子树贡献中**最大的两个**（都先与 0 取 max）相加。
- **112/113/437 路径总和系列**：约束不同（必须向下），思路完全不同，别混用。
