## 1. 二分查找

**左闭右开（主力模板，用于找边界）**

```cpp
int lowerBound(vector<int>& a, int target) {   // 第一个 >= target 的位置；都不满足返回 n
    int l = 0, r = a.size();                   // r = n，不是 n-1
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] < target) l = mid + 1;      // mid 不满足
        else r = mid;                          // mid 可能是答案，保留
    }
    return l;
}
// upperBound：把 a[mid] < target 改成 a[mid] <= target（第一个 > target）
// 出现次数 = upperBound - lowerBound
// 元素存在性判断：lo < n && a[lo] == target   ← 两个条件都要
```

**闭区间（查找精确值）**

```cpp
int search(vector<int>& a, int target) {
    int l = 0, r = a.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] == target) return mid;
        if (a[mid] < target) l = mid + 1;
        else r = mid - 1;
    }
    return -1;
}
```

**三者必须成套，禁止混搭**

| 区间 | 循环条件 | r 初值 | 收缩 |
|---|---|---|---|
| `[l, r)` | `l < r` | `n` | `r = mid` |
| `[l, r]` | `l <= r` | `n - 1` | `r = mid - 1` |

**旋转数组找最小值（153）**：**与 `a[r]` 比较**，不是 `a[l]`

```cpp
int l = 0, r = n - 1;                          // r 必须是有效下标
while (l < r) {
    int mid = l + (r - l) / 2;
    if (a[mid] > a[r]) l = mid + 1;
    else r = mid;
}
return a[l];
```

**二分答案框架**：找单调谓词的分界点。`check(x)` 关于 x 单调 ⟹ 可二分（287、4、378、875）。

**铁律**：`mid = l + (r - l) / 2` 防溢出；每轮必须缩小区间；`l = mid` 要配向上取整的 mid。

## 3. 二叉树

**递归三问**：返回什么？base case？在前/中/后序哪个位置干活？

**中序迭代**

```cpp
stack<TreeNode*> st;
TreeNode* cur = root;
while (cur || !st.empty()) {              // 两者都空才结束
    while (cur) { st.push(cur); cur = cur->left; }
    cur = st.top(); st.pop();
    /* 访问 cur */
    cur = cur->right;
}
```

**BFS 分层**（`sz` 必须提前存！）

```cpp
queue<TreeNode*> q; q.push(root);
while (!q.empty()) {
    int sz = q.size();                    // 关键
    for (int i = 0; i < sz; ++i) {
        TreeNode* node = q.front(); q.pop();
        if (node->left)  q.push(node->left);
        if (node->right) q.push(node->right);
    }
}
```

**「返回值 ≠ 答案」模式**（543、124、687）

```cpp
int gain(TreeNode* node) {
    if (!node) return 0;
    int l = max(gain(node->left), 0);         // 124 需要负数归零
    int r = max(gain(node->right), 0);
    best = max(best, node->val + l + r);      // 答案：以 node 为拐点
    return node->val + max(l, r);             // 返回：向上只能一条边
}
```

**BST 性质**：中序遍历 = 升序（98、230、530）。验证 BST 用**上下界 `long long`** 或中序 `prev` 指针。

## 4. 回溯

```cpp
void backtrack(状态) {
    if (终止条件) { ans.push_back(path); return; }
    for (候选 c) {
        if (剪枝) continue;
        path.push_back(c);      // ① 选
        backtrack(新状态);       // ②
        path.pop_back();        // ③ 撤销 ← 灵魂
    }
}
```

**for 循环起点决定题型（核心区别）**

| 类型 | 写法 | 题 |
|---|---|---|
| **排列** | `for (i = 0; ...)` + `used[]` | 46、51 |
| **组合/子集** | `for (i = start; ...)`，递归传 `i + 1` | 78、131 |
| **可重复取** | `for (i = start; ...)`，递归传 **`i`** | 39 |

**含重复元素去重**：先 `sort`，然后

```cpp
if (i > start && a[i] == a[i-1]) continue;    // 同层去重（i > start，不是 i > 0）
```

**子集**：`ans.push_back(path)` 放在**函数入口**（每个节点都是答案）。

## 5. 单调栈

```cpp
// 下一个更大元素（栈内递减，存下标）
stack<int> st;
for (int i = 0; i < n; ++i) {
    while (!st.empty() && a[st.top()] < a[i]) {   // 求"更小"就反过来用 >
        ans[st.top()] = i - st.top();             // 弹出即答案确定
        st.pop();
    }
    st.push(i);
}
```

**要点**：存**下标**（才能算距离）；**弹出的那一刻答案就位**；均摊 O(n)。

**84 柱状图（双哨兵，左右边界同时就位）**

```cpp
vector<int> h;
h.push_back(0);                                   // 左哨兵：保证栈非空，left 总能取到
for (int x : heights) h.push_back(x);
h.push_back(0);                                   // 右哨兵：保证所有元素被结算
int best = 0;
stack<int> st;
for (int i = 0; i < (int)h.size(); ++i) {         // 注意上界是加了哨兵之后的长度
    while (!st.empty() && h[st.top()] > h[i]) {
        int top = st.top(); st.pop();
        int left = st.top();                       // 弹出后的新栈顶 = 左边界
        best = max(best, h[top] * (i - left - 1)); // 宽度是 i - left - 1（-1 别忘）
    }
    st.push(i);
}
```

## 6. 堆

```cpp
priority_queue<int> maxHeap;                                 // 大顶堆（默认！）
priority_queue<int, vector<int>, greater<int>> minHeap;      // 小顶堆
```

**Top-K 口诀：求第 K 大用「大小为 K 的小顶堆」，求第 K 小用大顶堆**（方向是反的）。

**双堆求中位数（295）**

```cpp
priority_queue<int> lo;                                      // 大顶堆：较小的一半
priority_queue<int, vector<int>, greater<int>> hi;           // 小顶堆：较大的一半
void addNum(int num) {
    lo.push(num);                 // ① 无条件进左半
    hi.push(lo.top()); lo.pop();  // ② 把左半最大值让给右半（保证左 <= 右）
    if (lo.size() < hi.size()) { lo.push(hi.top()); hi.pop(); }   // ③ 平衡
}
double findMedian() {
    return lo.size() > hi.size() ? lo.top() : ((double)lo.top() + hi.top()) / 2.0;
}
```

**别写 `lo.size() - hi.size() > 1`**（无符号下溢），写加法 `lo.size() > hi.size() + 1`。

## 7. 动态规划

**四步**：状态定义 → 转移 → 初始化 → 遍历顺序。

**背包循环顺序（背下来）**

```cpp
// 完全背包（可重复取）：容量【正序】       —— 322、279、139、518
for (int c : items) for (int j = c; j <= W; ++j) dp[j] = min(dp[j], dp[j-c] + 1);

// 01 背包（每个一次）：容量【倒序】        —— 416、494、474
for (int c : items) for (int j = W; j >= c; --j) dp[j] = dp[j] || dp[j-c];
```

**为什么 01 要倒序**：倒序时 `dp[j-c]` 还是上一轮的值（未含当前物品），保证只用一次。

**方案数的循环顺序**
- **组合数**（不计顺序，518）：外层物品、内层容量
- **排列数**（计顺序，377）：**外层容量、内层物品**

**"无穷大"用 `amount + 1` 或 `n + 1`，不要用 `INT_MAX`**（`+1` 会溢出）。

**以 i 结尾的状态定义**（子数组/子序列最优值）：答案是 `max(dp[i])` **不是 `dp[n-1]`**（152、300、53）。

**双序列 DP（1143、72）**

```cpp
// dp[i][j] = s1 前 i 个 与 s2 前 j 个 的答案；表大小 (m+1)×(n+1)
// 字符是 s1[i-1]、s2[j-1]  ← off-by-one 是头号 bug

// 1143 LCS：边界全为 0（vector 默认初始化即可）
vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
for (int i = 1; i <= m; ++i)
    for (int j = 1; j <= n; ++j)
        if (s1[i-1] == s2[j-1]) dp[i][j] = dp[i-1][j-1] + 1;
        else                    dp[i][j] = max(dp[i-1][j], dp[i][j-1]);

// 72 编辑距离：边界非零！dp[i][0] = i（全删）、dp[0][j] = j（全插）
vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
for (int i = 0; i <= m; ++i) dp[i][0] = i;
for (int j = 0; j <= n; ++j) dp[0][j] = j;
for (int i = 1; i <= m; ++i)
    for (int j = 1; j <= n; ++j)
        if (s1[i-1] == s2[j-1]) dp[i][j] = dp[i-1][j-1];          // 相同不加 1
        else dp[i][j] = 1 + min({ dp[i-1][j-1],   // 替换
                                  dp[i-1][j],     // 删除（i 变小 = 删 s1 的字符）
                                  dp[i][j-1] });  // 插入
```

**网格 DP 一维优化**：**正序**遍历（`dp[j]` 是上一行、`dp[j-1]` 是本行）——与 01 背包相反。

**区间 DP（回文）**：`i` **倒序**、`j` 正序；`pal[i][j] = (s[i]==s[j]) && (j-i < 2 || pal[i+1][j-1])`。

## 8. 图论

**网格四方向**

```cpp
const int dx[4] = {-1,1,0,0}, dy[4] = {0,0,-1,1};
if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
```

**BFS 一层 = 一个时间单位**；**多源 BFS**：所有起点一次性全部入队（994、542、1162）。
**BFS 必须在入队时标记 `vis`**，不是出队时（否则队列爆炸）。

**拓扑排序（Kahn，207）**

```cpp
for (auto& p : prerequisites) { g[p[1]].push_back(p[0]); ++indeg[p[0]]; }   // 注意边方向
for (int i = 0; i < n; ++i) if (!indeg[i]) q.push(i);
int cnt = 0;
while (!q.empty()) {
    int u = q.front(); q.pop(); ++cnt;
    for (int v : g[u]) if (--indeg[v] == 0) q.push(v);
}
return cnt == n;                          // 关键收尾：计数比对判环
```

**DFS 判环必须三色**（0 未访问 / 1 在栈上 / 2 已完成）。只用 bool 会把 DAG 误判成有环。

**Trie（208）**

```cpp
struct Node { Node* ch[26] = {}; bool isEnd = false; };   // = {} 不能省
// search 检查 isEnd；startsWith 不检查 ← 唯一区别
```

## 9. 技巧速查

```cpp
a ^ a = 0, a ^ 0 = a          // 136 异或消消乐
x & (-x)                       // 最低位的 1
x & (x - 1)                    // 消掉最低位的 1
```

**Boyer-Moore 投票（169）**

```cpp
int cand = nums[0], cnt = 0;
for (int x : nums) { if (cnt == 0) cand = x; cnt += (x == cand) ? 1 : -1; }
// 不保证多数元素存在时，必须第二遍扫描验证
```

**三向切分（75）**：`[0,low)`=0、`[low,mid)`=1、`[mid,high]`未知、`(high,n)`=2

```cpp
while (mid <= high) {                                    // <= 不是 <
    if (a[mid] == 0) { swap(a[low++], a[mid++]); }
    else if (a[mid] == 1) ++mid;
    else { swap(a[mid], a[high--]); }                    // mid 不动！
}
```

**下一个排列（31）**：① 从右找第一个升点 `i`（`a[i] >= a[i+1]` 时继续左移）② 从右找第一个 `> a[i]` 的 `j`，交换 ③ 反转 `[i+1, n)`。`i == -1` 时第三步自动给出最小排列。

## 10. C++ 常用

```cpp
// 容器
unordered_map / unordered_set     // 平均 O(1)，默认选择
map / set                          // O(log n)，需要有序遍历时
multiset                           // 有序 + 可重复 + 支持删除（480 滑窗中位数）

// 算法
sort(a.begin(), a.end());
sort(a.begin(), a.end(), [](const auto& x, const auto& y){ return x[0] < y[0]; });

nth_element(a.begin(), a.begin()+k, a.end());   // 快速选择，平均 O(n)（215）
next_permutation(a.begin(), a.end());            // 31
reverse / accumulate / max_element / __builtin_popcount(x)

// pair 作 unordered_map 的 key（无默认哈希，需自定义）
struct PairHash {
    size_t operator()(const pair<int,int>& p) const {
        return hash<long long>()((long long)p.first << 32 | (unsigned)p.second);
    }
};
unordered_map<pair<int,int>, int, PairHash> mp;
// 临时救急：改用 map<pair<int,int>, int>（红黑树有默认比较）

// 结构化绑定（C++17）
for (auto& [k, v] : mp) { ... }
```

**易错点清单**
- `st.top()` / `q.front()` 前必须判空
- `size()` 是**无符号**：`(int)a.size() - 1`；不要写 `a.size() - b.size() > 1`
- `substr(start, len)` 第二个参数是**长度**不是结束下标
- `vector<bool>` 是位压缩特化，`vector<char>` 更快
- 循环里 `push` 时 `sz` 要提前存
- `int` 溢出：中间乘积、`l + r`、`INT_MAX + 1`、前缀和（437 要 `long long`）

## 11. 复杂度反推

| n | 可接受复杂度 | 典型算法 |
|---|---|---|
| ≤ 10 | O(n!) / O(2ⁿ·n) | 全排列回溯 |
| ≤ 20 | O(2ⁿ) | 子集枚举、状压 DP |
| ≤ 100 | O(n³) | Floyd、区间 DP |
| ≤ 1000 | O(n²) | 双序列 DP、朴素 LIS |
| ≤ 10⁵ | O(n log n) | 排序、堆、二分、单调栈 |
| ≤ 10⁷ | O(n) | 双指针、滑窗、前缀和 |
| ≥ 10⁹ | O(log n) / O(1) | 二分答案、数学、快速幂 |

**看到 `n <= 10^5` 基本排除 O(n²)** —— 从约束反推算法是最快的破题方式。

## 12. 一页版"卡住了怎么办"

1. **暴力是什么？** 先说出 O(n²)/O(2ⁿ) 的做法，再问"哪一步在重复劳动"。
2. **重复查找 → 哈希**；**重复区间计算 → 前缀和 / 单调栈**；**重复子问题 → DP / 记忆化**。
3. **有序 / 单调可判定 → 二分**（不一定要全局有序）。
4. **求最短步数 + 边权为 1 → BFS**；边权不同 → Dijkstra。
5. **"下一个更大/更小" → 单调栈**；**"窗口内最值" → 单调队列**。
6. **"第 K 个" → 堆或快速选择**；**"动态中位数" → 双堆**。
7. **列出所有方案 → 回溯**；**只要计数/最优值 → DP**。（78→416、39→322、131→132）
8. **值域 `[1,n]` 且长度 n 或 n+1 → 原地置换（41）或找环（287）**。
9. **状态需要额外信息才能转移 → 把它塞进状态定义**（300 的"以 i 结尾"、152 的"同时记最小"）。
10. **实在没思路**：手算 n=1,2,3 找规律，或画出递归树看重复在哪。
