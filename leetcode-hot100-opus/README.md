## 建议刷题顺序

**第一轮（打地基，约 3 周）**
1. 哈希 → 双指针 → 滑动窗口：建立「用空间换时间」和「单调收缩」的直觉
2. 栈 → 堆：容器的典型用法，单调栈是后面 42/84 的钥匙
3. 链表：机械但高频，练手感（哨兵节点 + 快慢指针 + 原地反转）
4. 二叉树：递归思维的训练场，必须练到不用想就能写

**第二轮（上强度，约 3 周）**
5. 二分查找：边界写法一次性统一，别每题重新想
6. 回溯：三段式模板 + 去重
7. 图论：BFS/DFS/拓扑排序
8. 普通数组 + 矩阵 + 技巧：技巧型题目，见过就会，没见过很难现场推

**第三轮（决胜区，约 2 周）**
9. 贪心 → 动态规划 → 多维 DP：DP 是分水岭，按「状态定义 → 转移 → 初始化 → 遍历顺序」的流程走
10. 回头攻困难题：4、23、25、32、41、42、76、84、124、146、239、295

## 复杂度速查

| 数据量 n | 可接受复杂度 |
|---|---|
| ≤ 10 | O(n!) / O(2ⁿ) 回溯 |
| ≤ 20 | O(2ⁿ) 状压 |
| ≤ 100 | O(n³) |
| ≤ 1000 | O(n²) |
| ≤ 10⁵ | O(n log n) |
| ≤ 10⁷ | O(n) |
| ≥ 10⁹ | O(log n) / O(1) 数学 |

看到 `n <= 10^5` 基本就排除 O(n²)——这是从题目约束反推算法的常用手段。
