# 06 · 矩阵（4 题）

## 套路总纲

**识别信号**：二维数组上的**原地操作**、**按特定顺序遍历**、或**利用有序性搜索**。

**四种独立技巧**：

| 题 | 技巧 | 一句话 |
|---|---|---|
| 73 矩阵置零 | **用矩阵自身的第一行/列当标记位** | O(1) 空间的原地标记 |
| 54 螺旋矩阵 | **四个边界变量收缩** | 别用方向数组硬转，用边界更清晰 |
| 48 旋转图像 | **转置 + 水平翻转** | 顺时针 90° = 主对角线翻转后左右翻转 |
| 240 搜索二维矩阵 II | **从右上角出发的"阶梯搜索"** | 站在能同时排除行和列的角上 |

**两条通用经验**：

1. **二维原地问题的核心矛盾**：「读」和「写」会互相干扰。解法要么找一个**不干扰的遍历顺序**，要么找一块**能复用的存储**（73 用第一行列），要么**推导出坐标映射公式**（48）。
2. **矩阵有序时先问"从哪个角开始"**。四个角里通常只有一两个能提供"排除一整行/列"的单调性——240 的右上角就是这样的支点。

### 73. 矩阵置零（中等）

**题意**  若矩阵中某元素为 0，则把它所在的整行和整列都置为 0。**原地**修改。

**暴力**  遍历时遇到 0 就立刻把该行该列清零 —— **错的**。清出来的新 0 会被后续遍历再次当成"原始 0"，导致整个矩阵被清空。这个陷阱是本题的出发点：**原地修改破坏了输入信息**。

正确的朴素做法：先扫一遍记录所有 0 的行号和列号（两个 `set`，O(m+n) 空间），再统一清零。这就是标准解，面试先给它。

**关键洞察**

要把 O(m+n) 降到 O(1)，需要一块**已经注定要被清零的存储区**——**第一行和第一列**就是这样的地方。

如果 `matrix[i][j] == 0`（`i,j > 0`），那么第 `i` 行第一个元素 `matrix[i][0]` 和第 `j` 列第一个元素 `matrix[0][j]` **反正都要变成 0**。所以可以把它们当成标记位：「第 i 行需要清零」记在 `matrix[i][0]`，「第 j 列需要清零」记在 `matrix[0][j]`。

**唯一的麻烦**：`matrix[0][0]` 被第一行和第一列共用，一个格子放不下两个标记。所以额外用一个布尔变量 `firstColZero` 单独记录第一列，让 `matrix[0][0]` 专管第一行。

**处理顺序也很关键**：标记写在第一行/列，所以内部区域必须**在读第一行列标记之前**处理完，而第一行/列本身必须**最后**清零（否则标记就被自己擦掉了）。

**最优解（C++，O(1) 空间）**

```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        bool firstColZero = false;            // 第一列是否要清零（单独存，避免与第一行争 [0][0]）

        // 1. 扫描全表，把标记写到第一行/第一列
        for (int i = 0; i < m; ++i) {
            if (matrix[i][0] == 0) firstColZero = true;
            for (int j = 1; j < n; ++j)                 // 注意 j 从 1 开始
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;                   // 标记第 i 行
                    matrix[0][j] = 0;                   // 标记第 j 列
                }
        }

        // 2. 从右下往左上处理内部区域（避开第一行/列，防止提前擦除标记）
        for (int i = m - 1; i >= 0; --i)
            for (int j = n - 1; j >= 1; --j)
                if (matrix[i][0] == 0 || matrix[0][j] == 0)
                    matrix[i][j] = 0;

        // 3. 最后处理第一列（第一行已在步骤 2 中通过 matrix[0][j] 处理）
        if (firstColZero)
            for (int i = 0; i < m; ++i) matrix[i][0] = 0;
    }
};
```

**对照解法（O(m+n) 空间，思路最清晰）**

```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        vector<bool> row(m, false), col(n, false);
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j)
                if (matrix[i][j] == 0) row[i] = col[j] = true;
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j)
                if (row[i] || col[j]) matrix[i][j] = 0;
    }
};
```

**复杂度**  时间 O(mn)，空间 O(1)（优化版）/ O(m+n)（朴素版）。

**边界与坑**
- **不能边遍历边清零**，见上文。
- 优化版里第二重循环 `j` 必须**从 1 开始**（第一列是标记区，不能被当作普通数据读写）。
- 处理内部区域时**从右下往左上**（或者先处理内部再处理第一行列，两种都行）。核心要求是：读 `matrix[i][0]`/`matrix[0][j]` 时它们还是标记而不是已被清零的数据。上面代码倒序遍历，`i=0` 那一行处理时用的 `matrix[0][j]` 标记仍完好，因为 `j>=1` 的位置在读取的瞬间才被写。
- 空矩阵要防 `matrix[0].size()` 崩——LeetCode 保证 `m,n >= 1`，但生产代码要判。
- 优化版把 `matrix[0][0]` 的语义定为「第一行是否清零」，因此步骤 2 中 `i=0` 时 `matrix[0][0]==0` 会把整个第一行清掉——这是对的。

**追问 / 变体**
- **用 `INT_MIN` 当哨兵标记**：如果题目保证矩阵不含某个特殊值，可以先把要清零的位置标成哨兵、最后统一改 0。但依赖数据范围假设，不够健壮。
- **289 生命游戏**：同样是「原地更新且新旧状态互相干扰」，解法是**用高位存新状态**（`state |= newState << 1`），第二遍右移取出。这是同类问题的另一种通用技巧，值得对照看。
- **只置零行不置零列**：简单得多，一遍扫描即可。

### 54. 螺旋矩阵（中等）

**题意**  按顺时针螺旋顺序返回矩阵中的所有元素。

**暴力**  用 `visited` 数组 + 方向数组，撞墙或撞到已访问就转向。O(mn) 时间、O(mn) 空间，能过但不优雅。

**关键洞察**

螺旋的本质是**四条边界不断向内收缩**。维护 `top, bottom, left, right`，每一轮走四条边：

```
→ 沿 top 行从 left 到 right，然后 ++top
↓ 沿 right 列从 top 到 bottom，然后 --right
← 沿 bottom 行从 right 到 left，然后 --bottom
↑ 沿 left 列从 bottom 到 top，然后 ++left
```

不需要 `visited` 数组——边界收缩天然保证不重复访问，空间降到 O(1)。

**唯一的难点是"最后一圈"**：当剩下的是单行或单列时，走完前两个方向后 `top > bottom` 或 `left > right`，此时**后两个方向必须跳过**，否则会重复输出。所以第三、四个方向前要各加一个 `if` 判断。

两种控制方式：
1. **每个方向前判断边界是否还合法**（下面代码采用，最直观）。
2. **用 `while (ans.size() < m*n)` 当循环条件，每步走完检查**。也常见。

**最优解（C++）**

```cpp
class Solution {
public:
    vector<int> spiralOrder(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        int top = 0, bottom = m - 1, left = 0, right = n - 1;
        vector<int> ans;
        ans.reserve(m * n);
        while (top <= bottom && left <= right) {
            for (int j = left; j <= right; ++j) ans.push_back(matrix[top][j]);      // →
            ++top;
            for (int i = top; i <= bottom; ++i) ans.push_back(matrix[i][right]);    // ↓
            --right;
            if (top <= bottom)                                                       // 防单行重复
                for (int j = right; j >= left; --j) ans.push_back(matrix[bottom][j]);// ←
            --bottom;
            if (left <= right)                                                       // 防单列重复
                for (int i = bottom; i >= top; --i) ans.push_back(matrix[i][left]);  // ↑
            ++left;
        }
        return ans;
    }
};
```

**复杂度**  时间 O(mn)，空间 O(1) 额外（不计输出）。

**边界与坑**
- **第三、四方向的 `if` 判断不能省**。用 `[[1,2,3]]`（单行）测：走完 `→` 后 `top=1 > bottom=0`，若不判断就会再从右往左输出一遍，答案变成 `[1,2,3,3,2,1]`。**这是本题唯一的真坑**，也是面试官必测的用例。
- 单列 `[[1],[2],[3]]` 同理会触发第四个方向的重复。
- 收缩语句的位置：每个方向走完**立刻**收缩对应边界，不要攒到最后一起改。
- 循环条件是 `&&` 不是 `||`。
- 内层循环用 `<=` / `>=`（闭区间边界），和边界变量的定义保持一致。混用开闭区间是差一错误的源头——**定好用闭区间就全程闭区间**。

**追问 / 变体**
- **59 螺旋矩阵 II**：生成 `1..n²` 的螺旋矩阵。同样的边界收缩，改成写入而非读取，且是正方形所以更简单。
- **885 螺旋矩阵 III**：从任意点出发、可以走出矩阵边界，这时边界法不适用，改用「按 1,1,2,2,3,3... 的步长模式转向」。
- **逆时针螺旋**：交换方向顺序即可。
- **对角线遍历**（498）：另一类顺序题，按 `i+j` 分组。

### 48. 旋转图像（中等）

**题意**  把 `n × n` 矩阵**原地**顺时针旋转 90°。

**暴力**  新开一个矩阵，`newMat[j][n-1-i] = mat[i][j]`，然后拷回。O(n²) 空间——题目明确要求原地，所以只能作为推导坐标公式的铺垫。

**关键洞察**

先推出坐标映射：顺时针 90° 后，原来第 `i` 行变成第 `n-1-i` **列**。即

```
mat[i][j]  →  mat[j][n-1-i]
```

（验证：`n=3`，左上角 `(0,0)` → `(0,2)` 右上角 ✓）

直接按这个公式原地做需要**四个一组循环交换**（`(i,j) → (j,n-1-i) → (n-1-i,n-1-j) → (n-1-j,i) → (i,j)`），只遍历左上角的四分之一区域。正确但下标容易写错。

**更好的办法：拆成两个简单操作。**

```
顺时针 90° = 沿主对角线转置 + 左右水平翻转
```

```
1 2 3      转置     1 4 7    水平翻转    7 4 1
4 5 6    ------>   2 5 8   -------->   8 5 2
7 8 9              3 6 9               9 6 3
```

两步都是 O(1) 空间的简单 `swap`，几乎不会写错。**这是本题的推荐答案**——把一个难推的映射分解成两个显然的映射，是很通用的解题智慧。

**最优解（C++）**

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        // ① 沿主对角线转置：只遍历上三角，避免交换两次换回去
        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j)
                swap(matrix[i][j], matrix[j][i]);
        // ② 每行左右翻转
        for (auto& row : matrix)
            reverse(row.begin(), row.end());
    }
};
```

**对照解法（四元素轮转，一次成型）**

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        for (int i = 0; i < n / 2; ++i)                  // 只处理上半部分的"环"
            for (int j = i; j < n - 1 - i; ++j) {        // 每环里除最后一个的部分
                int tmp = matrix[i][j];
                matrix[i][j]                 = matrix[n-1-j][i];
                matrix[n-1-j][i]             = matrix[n-1-i][n-1-j];
                matrix[n-1-i][n-1-j]         = matrix[j][n-1-i];
                matrix[j][n-1-i]             = tmp;
            }
    }
};
```

**复杂度**  时间 O(n²)，空间 O(1)。

**边界与坑**
- **转置时内层 `j` 必须从 `i+1` 开始**。从 0 开始会把每对元素交换两次，等于什么都没做——这是最经典的错误，写完务必用 3×3 手算验证。
- 顺时针 = 「转置 + 水平翻转」；**逆时针** = 「转置 + **垂直**翻转（上下翻转行的顺序）」，或者「水平翻转 + 转置」。方向搞反是另一个高频错误，记住一个再推另一个。
- 四元素轮转版的循环边界 `j < n-1-i` 用的是**开区间上界**，写成 `j <= n-1-i` 会导致每环的角落被转两次。
- 本题是方阵（`n × n`）才能原地旋转。**非方阵无法原地旋转**（形状都变了），必须开新矩阵。面试可以主动提这一点。
- `reverse(row.begin(), row.end())` 里 `row` 必须是引用（`auto&`），写成 `auto` 会拷贝一份、改的是副本。

**追问 / 变体**
- **逆时针 90°**：`for` 转置后改 `reverse` 列（即 `reverse(matrix.begin(), matrix.end())`）。
- **旋转 180°**：整体上下翻转 + 每行左右翻转（或者直接 `reverse` 展平后的序列）。
- **非方阵旋转**（如 `m×n → n×m`）：必须新开矩阵，`res[j][m-1-i] = mat[i][j]`。
- **867 转置矩阵**：本题的第一步单独成题。
- **867 + 48 + 54 + 59** 这一组题练一遍，二维坐标变换就不会再慌。

### 240. 搜索二维矩阵 II（中等）

**题意**  矩阵中每行从左到右升序、每列从上到下升序，判断目标值 `target` 是否存在。

**注意与 74 的区别**：74 题的矩阵是「整体展平后有序」（每行第一个 > 上一行最后一个），可以当一维数组二分。本题**只有行内和列内有序，行之间没有全局关系**——`matrix[1][0]` 可能小于 `matrix[0][3]`。所以不能整体二分。

**暴力**  逐个遍历 O(mn)。或者对每一行做二分 O(m log n)——这已经是个不错的答案，但还不是最优。

**关键洞察**

问「从哪个角开始搜索」。逐个考察四个角：

- **左上角 `(0,0)`**：向右变大、向下也变大。若 `target > 当前值`，两个方向都可能——**无法排除**，废了。
- **右下角 `(m-1,n-1)`**：向左变小、向上也变小，同样二义。废了。
- **右上角 `(0, n-1)`**：向左变小、向下变大——**两个方向是相反的**！
  - `matrix[i][j] > target` → 这一**列**从这里往下只会更大，整列都排除 → `--j`
  - `matrix[i][j] < target` → 这一**行**从这里往左只会更小，整行都排除 → `++i`
- **左下角 `(m-1, 0)`**：同样可行（向右变大、向上变小），对称写法。

每步排除一整行或一整列，所以最多走 `m + n` 步。这个搜索路径像一条楼梯，所以叫**阶梯搜索 / Z 字搜索**。

**这个"找单调性相反的角"的思路是本题的全部价值**——它能推广到任何"行列双向有序"的结构。

**最优解（C++）**

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size(), n = matrix[0].size();
        int i = 0, j = n - 1;                     // 从右上角出发
        while (i < m && j >= 0) {
            if (matrix[i][j] == target) return true;
            if (matrix[i][j] > target) --j;       // 当前值太大 -> 整列排除，左移
            else                       ++i;       // 当前值太小 -> 整行排除，下移
        }
        return false;
    }
};
```

**复杂度**  时间 O(m + n)，空间 O(1)。

**边界与坑**
- **必须从右上或左下开始**，从左上/右下开始逻辑不成立。这是本题唯一的思路关卡。
- 循环条件 `i < m && j >= 0`：两个方向的越界条件不对称（`i` 递增、`j` 递减），容易写错成 `j > 0`（会漏掉第 0 列）。
- 别误用 74 题的「展平二分」——本题矩阵不满足那个前提，会得到错误答案。
- 空矩阵要判（`matrix.empty() || matrix[0].empty()`），LeetCode 保证非空。
- O(m+n) 和 O(m log n) 谁更优取决于形状：`m` 很小、`n` 很大时（如 1×10⁶）二分更好。面试可以提这个权衡——**阶梯搜索并非在所有形状下最优**。

**追问 / 变体**
- **74 搜索二维矩阵**：整体有序 → 一维二分，`mid` 映射回 `(mid/n, mid%n)`。见 [11-二分查找](11-二分查找.md)。
- **返回目标出现的次数 / 位置**：阶梯路径上继续走即可。
- **378 有序矩阵中第 K 小的元素**：不能阶梯搜索，改用**「二分答案 + 用阶梯搜索统计 ≤ mid 的个数」**——这题把 240 当子过程用，是很漂亮的组合，强烈建议刷。
- **分治解法**：以中间元素为界把矩阵切四块，排除一块，递归三块。复杂度 O(n^1.58)，比 O(m+n) 差，属于"知道就好"。
